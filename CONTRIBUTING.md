# Contributing to DEVOS

1. Open an issue for bugs or proposals before large changes.
2. Preserve project-scoped security boundaries and keep changes focused.
3. Run `python -m ruff check 03-backend`, `python -m pytest -q`, and
   `cd 02-frontend && npm run build` before opening a pull request.
4. Never commit `.env` files, credentials, tokens, or runtime data.
5. Describe security implications and verification evidence.

See the [documentation index](./docs/README.md).
