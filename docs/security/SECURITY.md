# Security Policy

Do not disclose vulnerabilities in public issues. Report them privately using
GitHub's repository security features or email
[mdkhaleelurrahman51@gmail.com](mailto:mdkhaleelurrahman51@gmail.com?subject=DEVOS%20Security%20Report).

Include the affected area, reproduction steps, impact, and mitigation. Never
include secrets or private data. See the [root security policy](../../SECURITY.md).
