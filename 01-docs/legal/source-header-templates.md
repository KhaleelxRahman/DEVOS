## Purpose

These reusable notices provide a consistent attribution pattern for new DEVOS
source and documentation files. They are templates only; existing source files
must not be mass-edited to add headers.

## Python

```python
# Copyright (c) 2026 DEVOS
# Licensed under the Apache License, Version 2.0.
# See LICENSE for details.
```

## TypeScript

```typescript
/*
 * Copyright (c) 2026 DEVOS
 * Licensed under the Apache License, Version 2.0.
 * See LICENSE for details.
 */
```

## Markdown

```text
Copyright (c) 2026 DEVOS
Licensed under the Apache License, Version 2.0.
See LICENSE for details.
```

## Usage notes

- Preserve the existing copyright and attribution of third-party files.
- Add a header only to new original DEVOS files or when a maintainer explicitly
  requests a source-header migration.
- A header does not replace the repository `LICENSE` or `NOTICE` files.
- Do not use these templates to claim ownership of third-party dependencies,
  generated output, or user-created project files.
