**DEVOS** (pronounced "dev-ohs")

## Developer Operating System

## "Build. Architect. Deploy. Anywhere."

Enable developers to build, design, and deploy software projects efficiently from a unified web-based workspace with integrated AI assistance, version control, and deployment tools.

## Typography

### Font Families

#### Display/Headings

- **Font:** Inter, system-ui, sans-serif

- **Weight:** 700 (Bold) for H1, 600 (SemiBold) for H2/H3

- **Use:** Main headings, section titles, branding text

#### Body/Interface

- **Font:** Inter, system-ui, sans-serif

- **Weight:** 400 (Regular) for body text, 500 (Medium) for labels

- **Use:** All body text, UI labels, descriptions

#### Code/Terminal

- **Font:** "Source Code Pro", "Courier New", monospace

- **Weight:** 400 (Regular)

- **Use:** Code snippets, terminal content, file paths

### Size Scale

| Level | Size | Line Height | Use Case |
| --- | --- | --- | --- |
| **H1** | 32px | 1.2 | Page titles |
| **H2** | 24px | 1.3 | Section headings |
| **H3** | 20px | 1.4 | Subsections |
| **Body** | 16px | 1.5 | Main content |
| **Small** | 14px | 1.5 | Secondary text |
| **Code** | 12px | 1.6 | Code/terminal |

## Icon Design

### Icon System

- **Library:** Lucide React (for frontend)

- **Size:** 16px, 20px, 24px, 32px (standard scales)

- **Style:** Outlined, thin lines, 2px stroke weight

- **Color:** Inherit from text color or use semantic colors

### Icon Guidelines

- Use consistent stroke weight across all icons

- Ensure icons remain recognizable at smallest size (16px)

- Support both light and dark mode rendering

- Never distort or skew icons

### Prohibited Icon Sources

- ❌ Emoji

- ❌ Proprietary icons from Figma, Adobe, Sketch

- ❌ Screenshots from other products

- ❌ Unattributed icons from design sites

## Photography & Imagery

### Product Screenshots

- **Allowed:** Screenshots of actual DEVOS interface

- **Not Allowed:** Composite mockups, fake code, staged photos

- **Format:** PNG (transparent backgrounds) or JPEG (solid backgrounds)

- **Size:** 1920x1080 or higher; optimized for web

- **Source:** Official DEVOS product only

### Illustrations

- **Allowed:** Original SVG illustrations, AI-generated with disclosure

- **Not Allowed:** Proprietary illustrations from Dribbble, Behance, Pixar, Disney, etc.

- **Attribution:** If using AI generation, note "Generated with [tool name]"

- **Licenses:** Always verify CC0, CC-BY, or Apache-compatible licenses

### Background Images

- **Preferred:** Subtle gradients or patterns

- **Accessibility:** Ensure text remains readable (minimum 4.5:1 contrast)

- **Avoid:** Busy, distracting patterns; low-quality images

## Brand Voice & Messaging

### Tone

- **Professional but friendly** — Not corporate, not casual

- **Clear and direct** — Use simple language

- **Confident** — Demonstrate expertise without arrogance

- **Helpful** — Prioritize user success

### Language Guidelines

| Context | Tone | Example |
| --- | --- | --- |
| Error messages | Clear, actionable | "Failed to save file. Check your permissions." |
| Success messages | Encouraging | "Project created successfully!" |
| Feature descriptions | Benefit-focused | "Open-source AI assistant for every project" |
| Documentation | Step-by-step | "Follow these 5 steps to deploy..." |

### Prohibited Language

- ❌ Generic marketing clichés ("game-changing," "revolutionary")

- ❌ Technical jargon without explanation

- ❌ False claims ("faster than everything")

- ❌ Competitive attacks (naming competitors negatively)

### Branded Phrases (Original DEVOS Expressions)

| Phrase | Context | Usage |
| --- | --- | --- |
| "Build. Architect. Deploy. Anywhere." | Tagline | Marketing, headers, tagline contexts |
| "Your terminal, your rules" | Feature callout | Marketing messaging about terminal sandbox |
| "Code. Context. Create." | AI features | Describing AI assistant capabilities |
| "Open source, developer-first" | Positioning | Product differentiation |

## Usage Examples

### ✅ Correct Usage

1. **Descriptive Reference:**

   - "Built with DEVOS"
   - "DEVOS-powered workspace"
   - "Inspired by DEVOS architecture"

2. **In Documentation:**

   - "DEVOS provides an open-source developer environment"
   - "The DEVOS project enables..."

3. **In Code:**

   - Variable names: `devos_config`, `DEVOS_VERSION`
   - Comments: `# DEVOS workspace initialization`

### ❌ Incorrect Usage

1. **Implying Affiliation:**

   - ❌ "DEVOS by [Your Company]" (if not owner)
   - ❌ "Official DEVOS Partner" (unless authorized)
   - ❌ "DEVOS Technology" (misrepresents ownership)

2. **Trademark Abuse:**

   - ❌ "devos" as generic term
   - ❌ Modifying the logo
   - ❌ Using in company name without permission

3. **Misleading Claims:**

   - ❌ "Powered by DEVOS" (for unaffiliated product)
   - ❌ Using DEVOS brand to imply endorsement
